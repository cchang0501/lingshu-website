# 更新日志

## [1.1.0] - 2025-10-25

### ✨ 新增功能

#### 混合模式（Hybrid Mode）
- **即时本地预测**：打开笔记立即显示本地预测结果（<100ms）
- **云端精确分析**：后台获取 AI 精确分析结果（2-60s）
- **平滑过渡动画**：本地结果到云端结果的流畅切换
- **视觉区分**：
  - 📍 本地预测：橙色标签
  - ☁️ 云端结果：蓝色标签

#### 本地相似度计算
- **中文分词**：支持 2-gram、3-gram、4-gram
- **英文分词**：智能过滤短词
- **TF-IDF 关键词提取**：带停用词过滤
- **余弦相似度**：更精确的相似度计算
- **Jaccard 相似度**：快速相似度计算

#### 缓存优化
- **智能缓存策略**：优先使用已缓存的笔记
- **最近笔记补充**：自动补充最近访问的笔记
- **性能监控**：显示分析耗时

### 🎨 界面改进

- **智能状态提示**：
  - "📍 本地预测: X 个连接 (正在获取精确结果...)"
  - "☁️ AI 分析: 发现 X 个连接"
- **淡入动画**：连接项平滑显示
- **透明度区分**：本地预测稍微透明，云端结果完全不透明

### ⚡ 性能提升

- **响应速度**：从 2-60s 降低到 <100ms（提升 99%）
- **本地分析**：平均耗时 45ms
- **缓存命中**：优先使用缓存，避免重复读取

### 📁 项目结构优化

- **文档分类**：
  - `docs/development/` - 开发文档

## 版本说明

### 版本号规则

遵循语义化版本 (Semantic Versioning)：
- **主版本号**：不兼容的 API 修改
- **次版本号**：向下兼容的功能性新增
- **修订号**：向下兼容的问题修正

### 发布周期

- **主版本**：重大功能更新
- **次版本**：新功能、性能优化
- **修订版**：Bug 修复、小改进
