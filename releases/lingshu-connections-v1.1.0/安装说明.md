# 灵枢连接插件 - 安装说明

## 📦 安装步骤

### 方法 1: 手动安装（推荐）

1. **找到你的 Obsidian vault 目录**
   - Windows: `C:\Users\你的用户名\Documents\你的vault`
   - macOS: `~/Documents/你的vault`
   - Linux: `~/Documents/你的vault`

2. **创建插件目录**
   ```
   你的vault/.obsidian/plugins/lingshu-connections/
   ```

3. **复制文件**
   将以下文件复制到上述目录：
   - `main.js`
   - `manifest.json`
   - `styles.css`

4. **重启 Obsidian**

5. **启用插件**
   - 打开设置 → 第三方插件
   - 找到"灵枢连接"
   - 点击启用

---

## ⚙️ 配置

### 1. 获取 API Token

1. 访问 [灵枢网站](https://lingshu-app.pages.dev/index_zh.html)
2. 登录你的账号
3. 打开浏览器开发者工具（F12）
4. 在 Console 中输入：
   ```javascript
   localStorage.getItem('lingshu_auth_token')
   ```
5. 复制返回的 Token

### 2. 配置插件

1. 打开 Obsidian 设置
2. 找到"灵枢连接"
3. 粘贴 API Token
4. **确认"使用混合模式"已勾选** ✅（推荐）
5. 点击"测试连接"

## 🚀 使用

### 自动分析
打开任意笔记，插件会自动分析并在侧边栏显示连接。

### 手动分析
- 使用命令面板（Ctrl/Cmd + P）
- 输入"分析当前笔记"
- 回车

### 混合模式（新功能）⭐
- **本地预测**：立即显示（<100ms）
- **云端精确**：2-60秒后更新
- **即时反馈**：不再等待

## ❓ 常见问题

### Q: 插件不显示？
**A:** 
1. 检查文件是否正确复制
2. 重启 Obsidian
3. 确认已启用第三方插件

### Q: 连接测试失败？
**A:**
1. 检查 Token 是否正确
2. 检查网络连接
3. Token 可能已过期（30天有效期）

### Q: 本地预测不显示？
**A:**
1. 确认"使用混合模式"已勾选
2. 需要至少 5 个笔记
3. 查看浏览器控制台日志
